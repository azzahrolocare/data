Cara Mendapatkan Gemini API Key Gratis

  1. Buka situs resmi Google AI Studio di aistudio.google.com/app/apikey.
  2. Login menggunakan akun Google (Gmail) Anda.
  3. Klik tombol biru "Create API key" dan pilih proyek baru atau proyek yang tersedia.
  4. Salin kode yang berawalan AIzaSy..., lalu tempelkan pada kolom Gemini API Key di aplikasi ini dan klik Simpan lalu Uji Koneksi.
Gratis & Aman: Selama tidak menautkan akun penagihan (Billing), API Key gratis sepenuhnya. Kunci hanya disimpan di localStorage browser perangkat Anda sendiri.
